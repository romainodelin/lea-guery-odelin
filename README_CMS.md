## 💡 Cas d'Usage Courants

### Ajouter une Vidéo YouTube
1. Allez dans **Vidéos**
2. Cliquez **Ajouter**
3. Collez l'URL YouTube
4. Écrivez une description
5. **Publish** → C'est en ligne !

### Mettre à Jour Votre Biographie
1. Allez dans **À Propos**
2. Modifiez le texte
3. Ajoutez une nouvelle photo si besoin
4. **Publish** → Changement en ligne

### Ajouter un Nouveau Service
1. Allez dans **Services**
2. **Ajouter un nouveau service**
3. Remplissez les détails
4. **Publish**

### Partager un Événement
1. Allez dans **Parcours Artistique**
2. **Ajouter un événement**
3. Date, lieu, description
4. Photo optionnelle
5. **Publish**

## ❓ FAQ

**Q: Mes modifications ne s'affichent pas ?**
A: Attendez 5-10 min. Nettoyez le cache (Cmd+Shift+R).

**Q: Je me suis trompé, comment annuler ?**
A: Les modifications récentes sont dans GitHub. On peut revenir en arrière.

**Q: Puis-je programmer une publication ?**
A: Oui, utilisez la date "Publish at" si disponible.

**Q: Comment changer la langue du site ?**
A: Le sélecteur de langue est en haut du site (FR/EN/DE).

**Q: Puis-je uploader des vidéos ?**
A: Non, utilisez YouTube. Collez l'URL dans le CMS.

**Q: Puis-je modifier le design ?**
A: Non via le CMS. Contactez l'équipe technique.
